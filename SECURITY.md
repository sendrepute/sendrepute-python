# Security

Report vulnerabilities privately to support@sendrepute.com with affected
version, impact and a redacted reproduction. Never attach customer messages,
keys or personal information. Coordinate disclosure before publishing exploit
details. No response-time SLA is promised. Version 0.1.x is the supported line.

Keep credentials server-side. Use verified HTTPS and explicitly trusted
origins; never let message input choose the API destination. Paid analysis
requires consent. Test Django blocking/failure policy before applying it to
transactional mail. Avoid logging messages or full exception context.
